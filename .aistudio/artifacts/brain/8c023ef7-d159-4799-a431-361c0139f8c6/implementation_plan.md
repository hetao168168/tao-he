# 菁优网教师工作台全面升级与秒级扫码优化方案

为中学与小学教师、辅导老师打造的**菁优网智能教学与错题管理工作台**。本次方案针对用户提出的“扫码等待时间过长”核心痛点，从底层架构上摒弃原有的重量级无头浏览器冷启动流程，转为**直接调用菁优网与微信底层 HTTP 接口**，将二维码出码耗时从 10~15 秒骤降至 **300 毫秒以内**；同时提供**真实扫码与一键快速演示双模式**，并交付完整的学生档案、错题本、菁优题库检索与试题组卷打印导出系统。

---

## 用户的确认决策与关键路径

> [!IMPORTANT]
> 根据前序交互中的确认结果，已确定以下三项核心决策：
> 1. **秒级扫码优化路径**：直接通过 Express/Node 后端或客户端发起轻量级 HTTP 请求（`POST /api/MpWeixinLogin` 与 `POST /api/CheckMpWeixin`），不再在后台等待启动庞大的 Playwright Chromium 实例，实现毫秒级瞬间出码与平滑轮询。
> 2. **双模式支持**：同时内置**真实微信扫码登录**通道与**一键模拟演示登录**，满足无网络代理或离线演示场景下的快速测试。
> 3. **全套教学功能**：打造一体化工作台，包含：**学生档案管理**、**错题本（快照隔离机制）**、**菁优试题智能检索与导入**、以及**按错题一键组卷与 Word/HTML/打印导出**。

## 1. 业务概览与核心价值

- **目标用户**：小学、初中、高中学科教师，班主任及课后辅导家长。
- **解决痛点**：
  - **登录扫码极慢**：旧版本启动 Chromium 无头浏览器消耗大量 CPU 和 10+ 秒等待，优化后毫秒级展示微信票据高清二维码。
  - **错题管理碎片化**：纸质试卷或手机拍照零散无章，本系统按学生、年级、学科、掌握状态系统化归档。
  - **试题复练出卷费时**：手动剪贴试题排版耗费数小时，本系统一键筛选“未掌握错题”自动生成附带密封线、考生信息区、答题规范与答案解析的专业练习卷。
- **快照隔离原则**：错题库存储题目独立深拷贝快照（`snap`），后续题库更新或删除绝不污染学生的历史错题记录。

## 2. 界面视觉体验与交互规范

遵循现代专业教育工具与 SaaS 仪表盘设计宪章，拒绝通用 AI 廉价塑料感（无药丸胶囊堆砌、无虚假浮夸指标、无无意义脉冲绿点）：

- **视觉基调**：
  - **主色调**：沉稳学术蓝（`#1D4ED8` / `#2563EB`）与典雅墨白底色（`#F8FAFC`、`#FFFFFF`）。
  - **语义状态色**：未掌握采用琥珀橙（`#D97706`），已攻克采用竹青翠绿（`#059669`），严控使用范围，必须搭配明确文字说明。
  - **元数据纯净呈现**：学科、年级、难度、来源均采用纯文字与优雅字符间隔号（`·` 或 `/`），禁止给每一个标签套圆角药丸框。
- **排版与比例**：
  - 标题采用兼具严谨与现代感的高质感无衬线字体，正文行高 1.6，排版宽度适度。
  - 试卷生成预览模拟真实 A4 试卷黑白印刷排版，包括密封线、大题题头与选择题选项网格对齐。
  - 数据与分数一律启用等宽数字（`font-mono tabular-nums`），保障表格纵向完美对齐。
- **核心交互流程**：
  1. **闪电扫码登录窗**：点击登录浮窗即刻呈现 430×430 高清微信扫码图片，附带 110 秒倒计时进度条、轮询心跳呼吸动画与“一键演示模式”备选按钮。
  2. **学生总览看板**：直观展示待攻克错题总数、各科错题分布、高频错因雷达与重点关注学生列表。
  3. **菁优选题中心**：按学科学段分类，支持关键词即时检索与真题筛选，试题卡片清晰展示题干、选项排布与权威答案，支持“单题入库”与“批量录入错题”。
  4. **智能组卷中心**：勾选学生与学科条件，秒级生成试卷并支持在线调整分值、隐藏/显示答案页、一键下载与浏览器无损直接打印。

               │                              │
         REST API (JSON)               直接数据流 / 离线缓存
               ▼                              ▼
┌─────────────────────────────────────────────────────────────┐
│                 轻量级 Node / Express 后端服务                │
│  ├── 认证代理路由 (/api/jyeoo/qr/fast-start, /api/jyeoo/qr/poll)│
│  │   Direct HTTP 快速通道: 避开 Playwright 浏览器冷启动       │

└─────────────────────────────────────────────────────────────┘

### 扫码性能优化技术突破
1. **彻底解耦 Playwright 无头浏览器依赖**：
   - 旧逻辑：启动 Chromium（耗时 8-15 秒，消耗 200MB+ 内存）$\to$ 打开登录页 $\to$ 截图元素。
   - 新逻辑：Node 端 `fetch('https://www.jyeoo.com/api/MpWeixinLogin', { method: 'POST' })` 直接获取微信官方生成凭证 `{ ticket, url, appkey }`，网络往返仅需 **150~300ms**！
2. **二维码快速呈现**：
   - 前端接收到票据直接渲染微信高清官方二维码 `https://mp.weixin.qq.com/cgi-bin/showqrcode?ticket=...`，或由本地快速生成矢量 SVG 兜底。
3. **自适应心跳轮询**：
   - 保持 1.5 秒安全间隔轮询 `/api/CheckMpWeixin`，捕获用户扫码确认态（`S=2`）后自动保存会话 Cookie 并触发登录成功动效。
4. **演示模式无缝穿梭**：
   - 教师备课或离线演练时，点击“快速演示身份”，1 秒注入示范教师账户、完整初中数理化错题库与 5 名学生样本数据，开箱即用。

## 4. 实施阶段与模块设计

### 阶段一：基础框架与秒级扫码服务端实现
- 重构 Express 服务，集成轻量化 Jyeoo 直连 HTTP 请求客户端与会话存储；
- 编写 `fastQRLogin` 与 `pollQR` 接口，验证出码时间降至 <500ms。

### 阶段二：学生档案与错题快照管理
- 建立学生增删改查、班级年级分类与重点关注标签；
- 构建错题本模块，支持错因标注（审题、概念、计算、规范）、掌握状态切换与题目快照。

### 阶段三：菁优网试题检索与导入
- 覆盖 10 大学科（语文、数学、英语、物理、化学、生物、历史、地理、道法、科学）；
- 呈现完整题干、选项结构、答案判定（提取 `s sh` class 与权威文本）、难度与来源解析；
- 支持一键快捷选入本地题库或指派为某学生错题。

### 阶段四：错题组卷、排版与打印导出
- 组卷向导：选择学生 $\to$ 筛选未掌握错题 $\to$ 配置卷头、副标题、分值与答案页开关；
- 专业试卷打印排版引擎：A4 标准尺寸分页、密封线裁切提示、防换行选项布局；
- 支持导出标准 HTML 离线文档与浏览器原生打印转 PDF。

## 5. 验证与测试标准
- 扫码弹窗开启至二维码可扫状态时间 $\le 600\text{ms}$；
- 错题状态切换与组卷预览即时响应（$< 100\text{ms}$）；
- 题库删除题目时不影响错题本内历史快照；
- 打印与导出试卷在 Chrome 打印预览下保持完整分页与清晰格式。
